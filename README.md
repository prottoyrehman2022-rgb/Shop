# My Business

A business performance app: sales, orders, expenses, profit & loss and analytics.
Single-file app (`index.html`), no build step. Data is stored in the browser (localStorage).

## Run locally
Open `index.html` in a browser.

## Publish with GitHub Pages
Settings → Pages → Deploy from a branch → `main` / `(root)`.
